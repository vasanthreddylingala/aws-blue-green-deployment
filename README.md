# AWS Blue-Green Deployment Project

Production-ready Blue-Green deployment on AWS using Terraform, Ansible, Docker, and ALB.

- Infrastructure: Terraform (VPC, ALB, Target Groups, EC2, ECR)
- Configuration: Ansible (Docker & Host Provisioning)
- Application: React (Frontend), Java Spring Boot (Backend), MySQL 8.0 (Database)
- CI/CD: 14-Stage Declarative Jenkins Pipeline
